Script shell permettant d’automatiser des tâches système sous Linux, illustrant des compétences en **administration système**, **scripting** et **automatisation**.

---

## Résumé exécutif

Développement d’un script Bash visant à automatiser des opérations courantes d’administration système (gestion de fichiers, utilisateurs, processus ou services selon le script).

Objectif : démontrer la capacité à **industrialiser des tâches**, améliorer l’efficacité et réduire les erreurs humaines via l’automatisation.

---

## Périmètre technique

* OS : Linux
* Langage : Bash
* Exécution : ligne de commande
* Automatisation de tâches système

---

## Réalisations clés

* Utilisation de commandes système Linux

## Exemple d’utilisation

Exécution du script :

```bash
chmod +x script.sh
./script.sh
```

Avec arguments :

```bash
./script.sh argument1 argument2
```

---

## Exemple de structure Bash

```bash
#!/bin/bash

if [ "$1" == "test" ]; then
  echo "Mode test"
else
  echo "Mode normal"
fi
```
